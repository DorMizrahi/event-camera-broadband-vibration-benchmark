# Third-Party Scientific Software

This package invokes, but does not redistribute, V2E from the Sensors Group at
the Institute of Neuroinformatics, UZH/ETH Zurich.

Repository: <https://github.com/SensorsINI/v2e>

When publishing results based on V2E conversion, follow the repository's current
citation guidance. At the time this package was prepared, the referenced work was:

Y. Hu, S.-C. Liu, and T. Delbruck, "v2e: From Video Frames to Realistic DVS
Events," 2021 IEEE/CVF Conference on Computer Vision and Pattern Recognition
Workshops (CVPRW), 2021. Preprint: <https://arxiv.org/abs/2006.07722>.

The exact V2E revision and model parameters should be reported with scientific
results. Each generated experiment stores the complete command and resolved
parameters for this purpose.
