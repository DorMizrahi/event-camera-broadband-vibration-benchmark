# Measurement and validation boundaries

The 40,000-frame/s source samples motion every 25 µs (20 source frames per 2-kHz cycle). The archive stores event time in integer microseconds. v2e interpolation was disabled. Integer storage, emulator scheduling and a 50-µs analysis bin cannot establish the true timing or shape of motion between source frames. A bin spans two source intervals nominally. The loader sets time zero to the first retained event and evaluates supplied references on the original bin-center time axis. Reported phase includes that convention. No timing offset was fitted.

The automatic ROI uses positive accumulated spatial activity from the entire event record, its 99th percentile, a 10-pixel margin and a 16-pixel minimum size. The ROI, bidirectional gap handling, centered SG and full-record FFT all use offline information. A future online study could estimate ROI from a fixed past-only warm-up and track it with bounded latency. This requires evaluating loss of marker support and timing; the present data analysis makes no real-time claim.

The 240 × 180 sensor observes a single 5-pixel-radius circular marker on a uniform background. Across the 30 archived v2e argument logs, positive and negative thresholds are 0.2, threshold SD 0.03, refractory period 0.1 ms, shot noise 0 Hz, leak 0.01 Hz and photoreceptor cutoff 0 Hz. A threshold SD is part of the emulator configuration; its effect was never experimentally isolated. Background, illumination conditions, texture, marker size, leak, shot noise, refractory period and threshold parameters provide no independent sensitivity contrasts. Contrast changes across nine settings and is confounded with displacement and other factors. A bounded follow-up would hold trajectory fixed across repeated emulator seeds and independently vary a preregistered nuisance factor at a time, before testing selected interactions.

Units are pixels, px/s and px/s². A physical acceleration requires an independently established mapping from image displacement to physical motion, accounting for imaging geometry, depth and motion direction. A scale inferred from these references would violate the baseline definition. A calibrated physical reference and real camera are outside this benchmark.

The historical emulator version, commit and Python version remain unknown. The archived motion seeds (7301–7330) differ from the recorded v2e seed argument (0). The standalone generator is identified separately from the historical broadband generation scripts. Its default settings are not evidence that it regenerates identical historical streams.
