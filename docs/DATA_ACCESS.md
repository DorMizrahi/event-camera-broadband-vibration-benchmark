# Archived benchmark data

The study uses the 30-case synthetic event-camera benchmark referenced in the manuscript: [Zenodo record 22539609](https://zenodo.org/records/22539609).

The GitHub repository contains only code, parameter/configuration exports, output tables, and analysis figures. Raw `events.h5`, motion `ground_truth.csv`, metadata and `video.mp4` files remain in the separately archived dataset.

For reconstruction, `DATASET/checksums.sha256` must verify and `DATASET/experiments/experiment_001` through `experiment_030` must exist. `environment/archive_hashes.csv` provides additional recorded hash values.
